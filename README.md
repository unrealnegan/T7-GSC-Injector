## Controls

| Combination | Function |
| --- | --- |
| **L1 + R3** | Load the selected menu |
| **L1 + Right** | Select the next menu |
| **L1 + Left** | Select the previous menu |
| **L1 + OPTIONS** | Disable or enable inputs |
| **L1 + Triangle** | Show credits |

## Installation

Mod menus are included. Add any additional `.gscc` files to **`/data/ModMenuInjector`**

1. Copy the **`ModMenuInjector`** folder to **`/data`**
2. Copy **`mod_menu_injector.prx`** to **`/data/GoldHEN/plugins`**
3. Register the  **`mod_menu_injector.prx`** for your BO3 CUSA in **`/data/GoldHEN/plugins.ini`**

Make sure you are in the zm/mp/cp lobby before injecting
    You can add and remove .gscc while in game
